<details>
<summary><b>⚙️ Cara mengaktifkan snake animation (klik)</b></summary>

<br/>

1. Buat file `.github/workflows/snake.yml` di repo `YOUR_USERNAME/YOUR_USERNAME`.
2. Copy-paste isi di bawah ini.
3. Jalankan workflow sekali secara manual (tab **Actions → Generate Snake → Run workflow**).
4. Pastikan nama branch di gambar README cocok dengan branch default kamu (`main` / `master`).

```yaml
name: Generate Snake

on:
  schedule:
    - cron: "0 0 * * *"      # jalan otomatis tiap hari jam 00:00 UTC
  workflow_dispatch:          # bisa dijalankan manual
  push:
    branches:
      - main

permissions:
  contents: write

jobs:
  generate-snake:
    runs-on: ubuntu-latest
    timeout-minutes: 10
    steps:
      - uses: actions/checkout@v4

      - name: Generate snake
        uses: Platane/snk/svg-only@v3
        with:
          github_user_name: ${{ github.repository_owner }}
          outputs: |
            dist/github-snake.svg
            dist/github-snake-dark.svg?palette=github-dark&color_snake=#00f0ff&color_dots=#0d1117,#0969da,#bf5af2,#e040fb,#00ff9c
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}

      - name: Push snake to repo
        uses: stefanzweifel/git-auto-commit-action@v5
        with:
          commit_message: "chore: update contribution snake"
          file_pattern: "dist/*.svg"
```

</details>
